# Security reports

Rivet is early-stage desktop software. Only the latest source on `main` is maintained; no formal security audit is claimed.

Please report suspected vulnerabilities using GitHub's **Security → Report a vulnerability** option in this repository. Include the affected commit or version, a minimal synthetic reproduction, and the potential impact. Do not include real credentials, account tokens, personal databases, or campaign transcripts.

Ordinary bugs and build issues belong in public issues. Sensitive reports about credential storage, IPC trust boundaries, imported data, or unwanted data disclosure belong in private security reports.
